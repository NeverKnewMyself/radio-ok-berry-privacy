# Polityka prywatności Radio OK Berry

Publiczna, statyczna kopia polityki prywatności aplikacji Radio OK Berry. Strona nie używa JavaScript, plików cookie, analityki, reklam ani zewnętrznych skryptów.

Treść odpowiada przygotowaniu release 1.6.0 (1 października 2026 r.) i obejmuje lokalne wykrywanie wake word przez Vosk, zależne od dostawcy przetwarzanie SpeechRecognizer/TTS, diagnostyczne WAV oraz wyłączenie plików WAV z Android Backup. `index.html` oraz `privacy-policy.html` zawierają tę samą politykę, aby działał zarówno root strony, jak i bezpośredni adres dokumentu.

Kontakt w sprawach prywatności: radiookberry@gmail.com.
